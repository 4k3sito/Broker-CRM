# 4k3sito.github.io — OfficeScrapper

Repositorio de búsqueda de inmuebles comerciales (locales, oficinas, bodegas) en Monterrey, NL.
Stack: HTML/JS estático → Supabase (DB + auth) + FastAPI/PostGIS (spatial engine).
